# 大学生竞赛助手 APP — 需求分析文档（PRD v1.0）

> 项目阶段：第一阶段 / 需求分析
> 技术栈：HarmonyOS（ArkTS + ArkUI）+ AppGallery Connect 云服务 + 大模型 API
> 文档产出：产品经理

---

## 一、项目背景与目标

### 1.1 背景痛点
大学生参与学科竞赛（数学建模、挑战杯、互联网+、ACM、大创等）时普遍存在以下痛点：

| 痛点 | 具体表现 |
|---|---|
| 信息不对称 | 竞赛通知散落在教务处网站、公众号、QQ群，容易错过报名时间 |
| 备赛无规划 | 不知道从何准备，缺乏阶段性学习路径，临时抱佛脚 |
| 组队困难 | 想找队友但没有靠谱渠道，能力互补匹配难 |
| 经验断层 | 往届获奖经验口口相传，无法沉淀复用 |

### 1.2 产品定位
**一款面向大学生的「竞赛全周期助手」**：从发现竞赛 → 规划备赛 → 组队协作 → 复盘沉淀，用 AI 把备赛这件事变得有条理。

### 1.3 产品目标（MVP 阶段）
1. 让学生**不再错过**重要竞赛的关键时间节点（竞赛日历）
2. 让学生**知道怎么备赛**（AI 个性化学习规划）
3. 跑通"浏览竞赛 → 收藏 → AI 规划 → 提醒"核心闭环

## 二、目标用户分析

### 2.1 用户画像

**主要用户：有竞赛意愿的在校大学生（大一~研二）**

| 角色 | 特征 | 核心诉求 |
|---|---|---|
| 小白型（约 50%） | 大一/大二，没参加过竞赛，想尝试 | 有什么适合我的竞赛？怎么入门？ |
| 进阶型（约 35%） | 参加过 1-2 次，想冲奖 | 时间怎么安排？重点学什么？ |
| 大佬型（约 15%） | 多次获奖，带团队 | 组队招人、分享经验、获取认可 |

### 2.2 典型使用场景
- **场景 A**：开学初，想规划这学期参加什么竞赛 → 打开竞赛日历，按时间线浏览，收藏感兴趣的
- **场景 B**：报名了数学建模国赛，还有 3 个月 → 用 AI 生成 12 周备赛计划，每周收到提醒
- **场景 C**（P1 迭代）：想找会编程的队友 → 在组队广场发帖/应征
- **场景 D**（P1 迭代）：想看往届获奖攻略 → 浏览经验分享区

## 三、功能清单与优先级

### 3.1 P0 — 核心功能（MVP 必须交付）

| 编号 | 功能模块 | 功能描述 | 验收标准 |
|---|---|---|---|
| P0-1 | **竞赛日历时间线** | 按时间轴展示竞赛关键节点（报名开始/截止、比赛时间、结果公布），支持月份切换、分类筛选 | 首页默认展示当月及未来的竞赛节点；点击节点进入详情 |
| P0-2 | **竞赛详情页** | 展示竞赛全称、主办方、级别（国家级/省级/校级）、分类、时间线、官网链接、简介、适合人群 | 信息完整展示；支持收藏/取消收藏 |
| P0-3 | **竞赛收藏（我的竞赛）** | 收藏后进入"我的竞赛"列表，按时间紧急度排序 | 收藏状态云端同步 |
| P0-4 | **AI 学习规划** | 基于用户选定的竞赛 + 当前水平 + 可用时间，对话式生成阶段性备赛计划（周粒度） | 生成的计划包含阶段目标、每周任务、推荐资源方向 |
| P0-5 | **AI 对话页** | 类聊天界面，支持多轮对话追问、调整计划、计划导出为任务 | 对话流畅，计划可保存 |
| P0-6 | **用户系统** | 华为账号一键登录（AGC 认证服务），维护个人资料（学校、专业、年级、技能标签） | 登录后数据云端同步 |
| P0-7 | **基础数据后台** | 竞赛数据的云数据库存储与录入（运营预置 + 后续爬虫扩展） | 至少预置 30+ 主流竞赛数据 |

### 3.2 P1 — 增强功能（V1.1 ~ V1.3 迭代）

| 编号 | 功能模块 | 功能描述 |
|---|---|---|
| P1-1 | **智能提醒** | 报名截止前 7 天/3 天/1 天推送提醒；学习计划每日任务提醒（AGC 推送服务） |
| P1-2 | **组队广场** | 发布组队帖（所需技能、联系方式）、按竞赛/技能筛选、申请加入 |
| P1-3 | **经验分享社区** | 发帖（图文）、按竞赛标签聚合、点赞收藏评论 |
| P1-4 | **学习计划打卡** | AI 生成的计划转为每日任务，打卡记录进度，可视化完成率 |
| P1-5 | **搜索** | 竞赛名称/分类/级别关键词搜索 |

### 3.3 P2 — 远期功能（V2.0+）

| 编号 | 功能模块 | 功能描述 |
|---|---|---|
| P2-1 | **排行榜** | 校际/全国竞赛积分排行、个人成长徽章体系 |
| P2-2 | **获奖作品库** | 往届获奖论文/作品展示（需版权合规处理） |
| P2-3 | **AI 模拟答辩/评审** | 上传作品，AI 模拟评委提问与评分 |
| P2-4 | **校园大使/院校定制** | 学校管理员入驻，发布校内竞赛 |

### 3.4 优先级决策依据
- **P0 聚焦"信息 + 规划"闭环**：这是最小可用价值——即使只有日历和 AI 规划，产品也能独立成立
- **P1 补齐"人"的维度**：组队和社区依赖用户量，过早做会是空城
- **P2 是生态玩法**：需要内容沉淀和用户规模后才成立

## 四、信息架构（IA）

```
大学生竞赛助手
├── 首页（竞赛日历）
│   ├── 时间线视图（默认，按月分组）
│   ├── 日历视图（P1）
│   ├── 分类筛选（学科/创新创业/英语/体育艺术…）
│   └── 竞赛详情页
│       ├── 基本信息 + 时间线
│       ├── AI 规划入口（"为这场比赛做规划"）
│       └── 收藏按钮
├── AI 助手
│   ├── 对话页（学习规划主入口）
│   ├── 我的规划列表
│   └── 规划详情（阶段 + 周任务）
├── 广场（P1 开放，MVP 预留 Tab 位）
│   ├── 组队帖
│   └── 经验分享
└── 我的
    ├── 个人资料（学校/专业/年级/技能标签）
    ├── 我的竞赛（收藏）
    ├── 我的规划
    ├── 我的打卡（P1）
    └── 设置（提醒开关、关于）
```

**MVP 底部 Tab：首页（日历）| AI 助手 | 我的**（广场 Tab 在 P1 加入）

## 五、核心用户流程

### 5.1 主流程：发现竞赛 → AI 规划（核心闭环）

```
打开APP → 首页竞赛日历时间线
  → 筛选/浏览 → 点击"全国大学生数学建模竞赛"
  → 详情页查看时间节点与介绍 → 点击【收藏】+【AI备赛规划】
  → 跳转AI对话页（自动带入竞赛上下文）
  → AI 询问：当前水平？每周可投入时间？目标奖项？
  → 用户回答 → AI 生成 12 周分阶段计划
  → 用户可追问调整（"第5周任务太重了"）
  → 确认 → 保存为【我的规划】
  → （P1）报名截止前收到推送提醒
```

### 5.2 登录流程

```
首次启动 → 引导页（3屏介绍）→ 华为账号一键登录
  → 首次登录补全资料（学校/专业/年级/技能标签）
  → 进入首页
```

## 六、非功能性需求

| 类别 | 要求 |
|---|---|
| 性能 | 首页日历加载 < 1.5s；AI 首字响应 < 3s（流式输出） |
| 兼容性 | HarmonyOS 4.0+（API 11+），手机为主，预留平板自适应（响应式布局） |
| 安全 | 用户数据走 AGC 云数据库权限控制；AI 对话内容脱敏，不上传个人敏感信息 |
| 隐私 | 符合《个人信息保护法》，登录前展示隐私协议 |
| 可用性 | 云函数超时时有友好降级（AI 服务不可用时提示稍后重试） |

## 七、竞品参考（简析）

| 产品 | 优势 | 我们的差异点 |
|---|---|---|
| 赛氪 | 竞赛信息全、报名入口 | 重报名工具，无个性化备赛规划 |
| 超级课程表类 | 校园用户量大 | 无竞赛垂直功能 |
| 各竞赛公众号/群 | 信息及时 | 分散、无沉淀 |

**差异化核心：AI 个性化备赛规划 + 竞赛全周期管理**，不做报名工具，做"备赛教练"。

---

## 八、MVP 范围确认（本阶段结论）

**MVP = P0 全部 7 项功能**，目标：一个可安装、可登录、能看日历、能和 AI 聊出一份备赛计划的鸿蒙应用。

**明确不做（MVP 阶段）**：组队、社区、排行榜、打卡、爬虫自动抓数（先运营手工/脚本预置数据）。
