# 大学生竞赛助手 APP — UI/UX 设计规范（v1.0）

> 项目阶段：第三阶段 / UI 设计
> 设计产出：UI/UX 设计师
> 原则：简洁现代、信息层级清晰、符合大学生审美、鸿蒙设计语言（HarmonyOS Design）

---

## 一、视觉规范（Design Token）

### 1.1 色彩

| 用途 | 色值 | 说明 |
|---|---|---|
| 品牌主色 Primary | `#4F7CFF` | 按钮、选中态、链接、AI 强调 |
| 主色深 Variant | `#2F5BE0` | 按压态 |
| 成功/完成 | `#00C853` | 打卡完成、已收藏状态 |
| 警示/提醒 | `#FF6B35` | 报名截止临近、紧急节点 |
| 错误 | `#F5222D` | 失败提示 |
| 背景 Background | `#F5F6F8` | 页面底色 |
| 卡片 Card | `#FFFFFF` | 卡片背景 |
| 主文字 Text Primary | `#182431` | 标题、正文 |
| 次文字 Text Secondary | `#6B7785` | 说明、时间 |
| 分割线 Divider | `#E8EAEE` | 列表分割 |

> 说明：竞赛场景时间节点用 **警示橙 `#FF6B35`** 强调"即将截止"，成功/完成用绿色，符合通用语义（本 APP 无金融涨跌配色需求）。

### 1.2 字体与排版

- 字体族：HarmonyOS Sans（系统默认）
- 字号阶梯：大标题 28fp / 页面标题 22fp / 卡片标题 18fp / 正文 16fp / 辅助 14fp / 说明 12fp
- 行高：1.4 ~ 1.5

### 1.3 圆角与间距

- 卡片圆角 16vp，小卡片 12vp，按钮 24vp（胶囊）
- 页面左右边距 16vp，卡片内边距 16vp，元素间距 8/12/16vp

### 1.4 组件规范

- 按钮：主按钮（实心主色胶囊）、次按钮（描边）
- 标签 Tag：级别/分类用浅色底 + 主色文字
- 时间节点：左侧竖线 + 圆点 + 时间 + 标题（时间线组件）

## 三、页面数据契约（对接后端）

| 页面 | 数据来源 | 关键字段 |
|---|---|---|
| 首页时间线 | `comp-stages` 云函数 | `competitionName,type,title,time` |
| 竞赛详情 | `comp-detail` 云函数 | 竞赛全字段 + `stages[]` |
| AI 对话 | `ai-chat` + `plan-create` | 消息流 + 生成的 `plan/tasks` |
| 我的竞赛 | `fav-list` | 收藏竞赛列表 |
| 我的规划 | `plan-list` / `plan-detail` | 规划 + 周任务 |

---

## 四、交互与体验细节

1. **降级友好**：AI 生成失败时展示"稍后重试"而非白屏；时间线无数据时展示空态插画
2. **动效克制**：收藏/打卡用轻量过渡，避免花哨
3. **无障碍**：文字与背景对比度 ≥ 4.5:1；可点击元素 ≥ 44vp
4. **响应式**：手机为主，平板下时间线改两列卡片流
