## 二、后端部署（AppGallery Connect）

### 步骤 1：开通服务
1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)
2. 创建项目 + 应用（包名填客户端 `bundleName`：`com.campus.competitionassistant`）
3. 开通 **Cloud DB**、**Cloud Functions**、**Auth Service**

### 步骤 2：创建云数据库集合
按 `docs/02-数据库与云服务设计.md` 创建集合：`competition`、`competition_stage`、`user_profile`、`favorite`、`study_plan`、`team_post`、`share_post`

### 步骤 3：导入种子数据
```bash
cd cloudfunctions
node deploy.js        # 一键完成：语法校验 + 生成 seed-data.json + 打印部署清单
```
在 Cloud DB 控制台将 seed-data.json 的 `competition`（14 条）、`competition_stage`（19 条）数据导入。
（当前含 **14 场主流竞赛**、**19 个时间节点**，官网已联网核实。）

### 步骤 4：部署云函数
1. Cloud Functions 控制台创建函数，上传 `index.js` + `ai.js` + `package.json`
2. 环境变量：`DEEPSEEK_API_KEY = YOUR_DEEPSEEK_API_KEY`
3. 配置 HTTP 触发器，记录触发器地址

## 三、客户端接入（切换到云端）

编辑 `app/entry/src/main/ets/common/Constants.ets`：

```typescript
export class CloudConfig {
  static readonly USE_MOCK: boolean = false;              // 关闭本地 Mock
  static readonly CLOUD_FUNCTION_BASE: string = 'https://你的云函数触发器地址';
}
```

> `USE_MOCK = false` 后，**所有数据自动上云**：个人资料、发帖、收藏、学习规划、打卡、点赞全部经云函数写入 Cloud DB，跨设备、跨用户可见（见下「数据上云共享」）。
>
> AI 大模型由客户端「设置 → 模型配置」运行时选择（DeepSeek / Ollama / 本地模拟），不再依赖 `AiConfig.USE_MOCK_AI` 硬编码；也可改走云函数 `plan-create` 由服务端持有 Key（见 `cloudfunctions/index.js`）。

### 3.1 登录（华为账号一键登录 / Account Kit）

客户端已实现「华为账号一键登录」完整代码（`service/AuthService.ets` + `Login.ets` + `SettingsPage.ets`）。登录采用 **Account Kit（`@kit.AccountKit`）的 `authentication` 模块**，拉起华为账号授权后拿到 `openID`/`unionID`，作为用户在云端的唯一标识。`CloudConfig.USE_MOCK = true` 时走模拟登录（本地体验），`false` 时走真实华为账号登录。

接入真实登录只需在 **AGC 控制台** 完成以下配置（代码无需改动）：

1. **创建 AGC 项目与应用**：登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，包名填 `com.campus.competitionassistant`。
2. **登记签名 SHA256 指纹**：AGC「项目设置 → 常规 → 应用 → SHA256 证书指纹」填入你签名证书的指纹（未登记会报错误码 `1001500001`）。
3. **配置 Client ID**：AGC「项目设置 → 应用信息」复制 `Client ID`，替换 `app/entry/src/main/module.json5` 中 `metadata` 里 `client_id` 的占位值 `YOUR_AGC_CLIENT_ID`。
4. **真机运行**：签名打包后安装到真机（需登录华为账号），点击登录即可拉起华为账号授权。

> **数据归属机制**：登录成功后客户端把 `openID` 写入本地（`user_openid`），每次调用云函数时自动注入请求体（`openid` 字段）。云函数 `currentUserId(context, event)` 优先取 `event.openid`，作为每条数据的 `_openid` 归属标识，实现「收藏 / 规划 / 个人资料」按用户隔离、「发帖 / 排行榜」全员共享。
>
> **可选升级（AGC Auth Service）**：如需手机号/邮箱/匿名等更多登录方式，可再接入 `@hw-agconnect/auth` SDK（`ohpm install @hw-agconnect/auth`，`agconnect-services.json` 放 `AppScope/resources/rawfile/`），此时云函数会自动优先使用 `context.getUserId()`。当前 Account Kit 方案已满足「华为账号一键登录」需求，无需额外 SDK。

> 未登录时 `openid` 为空串，`favorite`/`study_plan`/`user_profile` 等依赖 `_openid` 的接口会退化为「全体共享同一条」；正式上架前务必引导用户登录。

### 3.2 数据上云共享（核心）

`USE_MOCK = false` 后，客户端 `service` 层各方法自动路由到云函数，落到 Cloud DB 实现**全员可访问**：

| 客户端功能 | 调用方法 | 云函数 action | Cloud DB 集合 | 共享范围 |
|---|---|---|---|---|
| 竞赛列表 / 详情 | `CloudService.getCompetitions/getCompetitionDetail` | `comp-list` / `comp-detail` | competition, competition_stage | 全员 |
| 时间线节点 | `CloudService.getStages` | `comp-stages` | competition_stage | 全员 |
| 收藏 / 取消 / 列表 | `CloudService.toggleFavorite/isFavorite/getFavorites` | `fav-toggle` / `fav-list` | favorite | 按 `_openid` 私有 |
| 学习规划（保存/列表/详情/打卡） | `CloudService.savePlan/getPlans/getPlanById/toggleTask` | `plan-save` / `plan-list` / `plan-detail` / `plan-task-toggle` | study_plan | 按 `_openid` 私有 |
| 组队帖（列表/发布） | `SocialService.getTeamPosts/createTeamPost` | `team-list` / `team-create` | team_post | 全员可见 |
| 经验帖（列表/发布/点赞） | `SocialService.getSharePosts/createSharePost/toggleLike` | `share-list` / `share-create` / `share-like` | share_post | 全员可见 |
| 排行榜 | `SocialService.getRankList` | `rank-list` | （演示数据，可替换为统计） | 全员 |
| 个人资料（读/写） | `UserService.getProfile/saveProfile` | `profile` | user_profile | 按 `_openid` 私有 |

**字段规范化**：云数据库文档 `_id` 统一映射为客户端期望的 `id`（`toClient`），并剥离内部字段 `_openid`，客户端无需感知存储差异。

**发帖数据流**（以经验帖为例）：
1. 用户点「发布」→ `SocialService.createSharePost(post)`
2. 云函数 `share-create` 写入 `share_post` 集合（含 `_openid`、`authorName`、`likes=0`）
3. 其他用户打开广场 → `share-list` 读全部帖子 → 即时看到新帖
4. 点赞 → `share-like` 对 `likes` 字段 `inc(1)`

**规划数据流**：
1. `AiService.generatePlan()` 本地/云端生成 `StudyPlan`（含客户端生成的 `id`）
2. `CloudService.savePlan()` → `plan-save` 按 `id` 去重后写入 `study_plan`
3. `plan-list` / `plan-detail` 读取；`plan-task-toggle` 切换 `doneTasks` 打卡状态

## 五、华为应用市场上架流程

1. **实名认证**：注册华为开发者账号并完成企业/个人实名
2. **软著**：软件著作权登记（App 上架必需，办理约 1-2 月）
3. **签名打包**：DevEco Studio 生成正式签名 → `Build > Build App(s)` 生成正式 AAB/APP
4. **提交审核**：上传应用、填写信息、上传隐私政策与用户协议、提交审核
5. **上架**：审核通过后发布

> 上架前务必完成「第四节检查清单」中所有 ⬜ 项。
